## 1. 设计基调（五条铁律）

1. **纯黑基底**：背景近纯黑（#050505），拒绝深蓝灰「泥感」
2. **零色相表面**：卡片/面板用无色相灰阶（#0D0D0D / #141414 / #1E1E1E），层次靠亮度差不靠色相
3. **纯白文字**：主文字 #FFFFFF，次级 60% 白，禁用中灰正文
4. **高饱和双强调**：青 #00E5FF（主操作/可用/运行），粉紫 #C77DFF（工具/增强/需注意）；红色仅留给危险态
5. **克制辉光**：neon 辉光只给两处——主 CTA（启动按钮）与运行中状态；大面积禁用

整体气质：极简、对称、留白充足；信息密度低（一次一个视觉焦点）。

## 2. 设计系统（Design Tokens）

### 2.1 色彩

| Token | 值 | 用途 |
|-------|-----|------|
| `bg/base` | #050505 | 窗口背景 |
| `bg/surface-1` | #0D0D0D | 卡片、面板 |
| `bg/surface-2` | #141414 | 嵌套区域、hover 态 |
| `bg/surface-3` | #1E1E1E | 输入框、代码块 |
| `border/hairline` | rgba(255,255,255,0.08) | 发丝分隔线 |
| `text/primary` | #FFFFFF | 主文字 |
| `text/secondary` | rgba(255,255,255,0.60) | 次级文字 |
| `text/disabled` | rgba(255,255,255,0.30) | 禁用 |
| `accent/cyan` | #00E5FF | 主强调：启动、Verified/Compatible、Running |
| `accent/fuchsia` | #C77DFF | 次强调：工具域、L1/L3 标签、Unknown |
| `status/danger` | #FF4757 | Incompatible、Broken、高风险确认 |
| `glow/cyan` | 0 0 24px rgba(0,229,255,0.35) | 主 CTA 与运行中辉光 |
| `glow/fuchsia` | 0 0 16px rgba(199,125,255,0.30) | 工具启用态微辉光 |

### 2.2 状态语义映射（两维状态模型，00 基石 §5.7）

| 状态 | 颜色 | 视觉 |
|------|------|------|
| 游戏运行中 Running | 青 | 发光圆点 + 微辉光 |
| 游戏可更新 UpdateAvailable | 粉紫 | 描边胶囊 |
| 游戏异常 Broken | 红 | 填充胶囊 |
| 工具 Verified / Compatible | 青 | 对勾图标 |
| 工具 Unknown | 粉紫 | 问号图标 + 行动建议 |
| 工具 Incompatible / Deprecated | 红 | 叉/横线图标 + 阻止说明 |
| 风险等级 L1 | 粉紫描边 | 「L1 配置修改」标签 |
| 风险等级 L3 | 粉紫+红点描边 | 「L3 进程级」标签，默认关闭 |

### 2.3 字体 / 间距 / 圆角

- 字体：中文 PingFang SC / MiSans（fallback：Microsoft YaHei / Segoe UI，缺字体不得破坏布局）；拉丁与数字 Inter；版本号/哈希用等宽（JetBrains Mono）
- 字阶：页面标题 20px / 卡片标题 16px / 正文 14px / 辅助 12px
- 间距：8px 基数；页面内边距 32px；卡片内边距 24px；卡片间距 16px（留白充足优先）
- 圆角：卡片 12px / 按钮 8px / 徽标胶囊 999px
- 组件基准：游戏封面卡 16:9；主 CTA 高 48px 全宽或大尺寸
- 缩放：基准 1280×800 @100%，须支持 125% / 150% DPI 缩放与多显示器（实现细节归 04 技术设计）

## 4. Stitch 使用说明

1. **先生成 S1 锁风格**：S1 通过后，后续提示词在同一会话追加「keep the exact same visual style as the previous screen」，保证一致性
2. **全局前缀**：每条提示词已内嵌全局前缀（见 5.0），也可将前缀存入 Stitch 自定义主题后简化各条
3. **一次一屏**：Stitch 单次生成一屏；状态变体（空态/警示态）作为后续迭代指令补充
4. **产出归档**：生成的 Figma 按本文编号命名（`Orbis/S1-Home` …），并在 Figma 中对照 §6 验收清单校对
5. **语言**：提示词用英文（Stitch 对英文理解最佳），UI 文案要求输出中文
6. **示例数据**：提示词中的版本号等均为假数据（与 00 基石示例体系对齐：原神 6.x、鸣潮 3.x），仅用于生成示意，不代表真实版本策略

## 5. 页面规格与 Stitch 提示词

### 5.0 全局风格前缀（S0）

每条提示词的开头统一使用（下文各条已内置，单独复制此条可存为自定义主题）：

```text
Design a desktop application UI for "Orbis", a minimal anime-game launcher
for Windows (1280x800). Visual style: pure black background #050505; card
surfaces in neutral zero-hue grays #0D0D0D / #141414 with hairline borders
rgba(255,255,255,0.08); pure white text #FFFFFF, secondary text 60% white;
high-saturation cyan #00E5FF as primary accent (used for main CTA buttons
and "running" states, with a subtle neon glow on primary CTAs only);
fuchsia purple #C77DFF as secondary accent for tools/enhancement features;
red #FF4757 reserved for danger states only. Extremely minimal layout,
generous whitespace, 8px spacing grid, 12px card radius, flat design, no
gradients, no illustrations. All UI copy in Simplified Chinese. One visual
focus per screen.
```

### 5.1 S1 · 首页（D1：三问一处可见）

**规格**：顶栏极简（左 Orbis 字标 + 右窗口控制）；「最近游玩」横排大卡 + 「全部游戏」网格卡（封面/名称/区服/时长/状态徽标）；存在需处理项时顶部出现摘要条（粉紫描边，列出「游戏可更新 / 工具未验证」计数，点击滚动定位）。

**Stitch 提示词**：

```text
[全局前缀] Screen: Home. Top minimal bar: small "Orbis" wordmark left,
window controls right. Below, a slim attention strip with fuchsia outline:
"2 个游戏需要处理 · 1 个更新可用" with a small arrow. Section "最近游玩":
a horizontal row of 3 large game cards (16:9 cover, game name, status pill;
one card shows a glowing cyan "运行中" dot badge). Section "全部游戏":
a grid of 5 game cards, each with cover art, game name, region tag
(国服/国际服), playtime, and a status badge — mix of states: cyan check
"已验证", fuchsia outline "可更新", one fuchsia pill "工具未验证".
Cards are spacious, 16px gaps, large whitespace between sections.
```

**迭代指令（空状态）**：

```text
Show the empty state variant of this Home screen: no games installed.
Centered composition: minimal placeholder icon, headline "未找到已安装的游戏",
subtext "确认游戏已通过官方渠道安装，或手动添加", a primary cyan glowing
button "重新扫描", and a ghost text button "手动添加游戏".
```

### 5.2 S2a · Game Dashboard 鸣潮（D2）

**规格**：左上返回；英雄区（封面 + 名称/区服/版本 + 今日/本周/总计时长）；主 CTA「启动」（青填充 + 辉光，48px+）；Enhancement 卡片（粉紫域）：「120 FPS 解锁」、状态「未启用」、风险标签「L1 配置修改」、兼容状态「已验证 ✓」、启用按钮；「配置历史」入口卡（最近备份时间 + 触发方式 + 「查看全部」，底层文件与哈希仅 Advanced 层展示）。

**Stitch 提示词**：

```text
[全局前缀] Screen: Game dashboard for the game "鸣潮". Top-left back button
"← 首页". Hero area: game cover on the left, game title "鸣潮", region tag
"国服", version "3.x", and playtime stats row "今日 1.2h · 本周 6.5h ·
总计 128h". A large full-width primary CTA button "启动" in filled cyan with
soft neon glow. Below, an Enhancement card with fuchsia left border: title
"120 FPS 解锁", status "未启用", a risk tag "L1 配置修改" (fuchsia outline
pill), compatibility line with cyan check "已验证 · 适用当前版本", and a
fuchsia "启用" button. Next to it a "配置历史" card: latest backup line
"今天 14:32 · 自动备份", link "查看全部". Generous spacing, single
column layout, calm hierarchy.
```

### 5.3 S2b · Game Dashboard 原神（B7/B8）

**与 S2a 的差异**：Enhancement 卡片带「实验性」角标、状态「默认关闭」、风险标签「L3 进程级」（粉紫描边 + 红点）、按钮为「了解并启用」而非直接「启用」；无配置历史卡（运行时解锁不落盘）。

**Stitch 提示词**：

```text
[全局前缀] Same game dashboard layout as before, for the game "原神".
Hero area with cover, region tag "国服", version, playtime stats, and the
large cyan glowing "启动" CTA. Enhancement card with fuchsia left border and
a small "实验性" corner badge: title "120 FPS 解锁", status "默认关闭",
risk tag "L3 进程级" (fuchsia outline pill with a red dot), compatibility
line with cyan check "已验证 · 适用当前版本", button "了解并启用" in
fuchsia outline style. A small caption below the button: "游戏重启后自动
恢复原状". No configuration history card. Keep the same calm, spacious
hierarchy.
```

### 5.4 S2c · Game Dashboard 通用型（无 Enhancement 游戏，D2/A4–A7）

**规格**：星铁 / 绝区零 / 终末地等广度层游戏使用；英雄区与主 CTA 同 S2a；「启动参数」卡片（A7，可折叠编辑）；「配置备份」卡片为禁用态「该游戏暂不支持配置备份」（Provider 声明前，A8 范围规则）；无 Enhancement 卡片。

**Stitch 提示词**：

```text
[全局前缀] Same game dashboard layout as before, generic variant for games
without enhancement tools (use "崩坏：星穹铁道" as the example game). Hero
area: cover, region tag "国服", version, playtime stats, and the large cyan
glowing "启动" CTA. Below: a "启动参数" card showing one saved launch
argument with an "编辑" ghost button; next to it a "配置备份" card in a
disabled state with a dimmed caption "该游戏暂不支持配置备份". No
enhancement card. Same calm, spacious hierarchy.
```

### 5.5 S3 · 工具详情 + L3 风险授权（C2/C3/B7）

**规格**：模态或独立页；工具名/版本/来源/License（MIT）；**组件下载步骤**（发行包分离：主包不含注入器，首次启用从 Orbis Releases 独立资产下载 + 哈希校验，对应 01 清单 B7）；权限清单（读取游戏进程、运行时注入、不修改游戏文件——每项图标+说明）；兼容状态行；风险披露块（进程级说明、社区历史、**不承诺绝对安全**）；显式勾选「我已了解风险并自愿启用」→「启用解锁」按钮由禁用变可用；次按钮「暂不启用」。无任何黑暗模式。

**Stitch 提示词**：

```text
[全局前缀] Screen: Tool detail and consent flow, as a centered modal dialog
over a dimmed dashboard. Title "原神 120 FPS 解锁", meta row "v2.4.1 ·
社区开源 · MIT". A first step row: "下载组件 · 来自 Orbis Releases · 附哈希
校验" with a subtle download progress bar. A permissions list with icons:
"读取游戏进程", "运行时注入（不修改游戏文件）", "游戏重启后自动恢复".
A compatibility row with cyan check: "当前版本 6.x 已验证". A risk
disclosure block on surface-2 background: plain-language text about
process-level modification, community history, and a bolded line "本项目
不承诺绝对安全，风险由你知情承担". At the bottom: a checkbox "我已了解
风险并自愿启用", and a primary fuchsia button "启用解锁" that appears
disabled until the checkbox is checked, plus a ghost secondary button
"暂不启用". Transparent, calm, no urgency tricks.
```

### 5.6 S4 · 增强执行流（D4 透明卡片，B2–B4）

**规格**：鸣潮启用 120FPS 的执行面板；三步行——①「备份配置」✓ 完成（时间）→ ②「修改帧率上限 60 → 120」进行中（青色进度）→ ③「验证修改」待执行（灰）；底部预留 Result 摘要区；底层信息（LocalStorage.db / 键名 / 哈希）收入弱化的「高级详情」次行（00 基石 §12.2 分层：默认层只见动作与结果）；角落一行小字「所有操作已写入统一日志」。

**Stitch 提示词**：

```text
[全局前缀] Screen: Enhancement execution flow, a step panel overlay for
"鸣潮 · 120 FPS 解锁". Header "正在执行 · 透明可回滚". Three step rows,
each with step number, action label, and status on the right: row 1
"备份配置" with cyan check and caption "今天 14:32"; row 2 "修改帧率上限
60 → 120" with an animated cyan progress bar; row 3 "验证修改" in disabled
gray "等待中". Below the steps, a dimmed collapsed line "高级详情" in
small secondary text showing "LocalStorage.db · KeyCustomFrameRate ·
a3f9c2". A reserved result summary area at the bottom with hairline
border. Tiny footer caption "所有操作已写入统一日志". Calm, clinical,
trustworthy.
```

**迭代指令（失败回滚态）**：

```text
Show the failure variant: step 2 shows a red "修改失败" tag, step 3 becomes
"已自动回滚" with a cyan check, and the result area shows "已恢复至今天
14:32 的备份 · 与原配置一致" with a ghost button "查看配置历史".
```
